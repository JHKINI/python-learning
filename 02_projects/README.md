## 🎳 볼링 점수 계산기 (`bowling/`)

랜덤으로 투구 결과를 만들고 10프레임 볼링 점수를 계산합니다.
스트라이크는 다음 2구, 스페어는 다음 1구를 보너스로 더해야 해서 **"아직 점수를 확정할 수 없는 프레임"을 어떻게 관리할지**가 핵심이었습니다.

| 단계 | 파일 | 무엇을 바꿨나 |
|---|---|---|
| 1 | `01_0423_list_design.py` | 프레임별 쓰러진 핀, 추가점수, 누적점수를 담을 리스트 구조부터 설계 |
| 2 | `02_0423_bonus_update.py` | `다음투구결과를더하는횟수` 배열을 두고, 새 투구가 나올 때마다 보너스가 남은 과거 프레임에 점수를 더함 |
| 3 | `03_0423_function_10th_frame.py` | 과거 프레임 업데이트를 함수로 분리. 투구가 최대 3번인 10프레임을 따로 처리 |
| 4 | `04_0423_frame_index_am.py`, `05_0423_frame_index_pm.py` | 다른 방식 시도: 프레임 인덱스와 투구 수로 진행 상태를 관리 (`계산가능()`, `누적점수계산()`) |
| 5 | `06_bowling_refactor.py` | 두 방식을 비교하면서 다시 정리 |
| 6 | `07_bowling_score_final.py` | 최종본. 점수 확정 여부(`프레임당점수계산완료여부`)를 따로 관리하고, 결과표에 `X` `/` 표시 |
| 7 | `08_bowling_score_flet.py` | 같은 로직에 Flet GUI를 붙임 |

설계할 때 쓴 손필기(프레임별 보너스 화살표 그림)는 [`notes/python.md`](../notes/python.md#볼링-점수-계산-설계)에 있습니다.

```text
============================================================
볼링 게임 결과
============================================================
 1프레임 : 2 1        프레임점수 =   3 누적점수 =   3
 2프레임 : 8 /        프레임점수 =  13 누적점수 =  16
 ...
 5프레임 : X          프레임점수 =  16 누적점수 =  44
 ...
최종 점수 : 77
```

## 🛒 마트 장바구니 · 재고 · 매출 관리 (`market/`)

장바구니 계산, 재고 관리, 날짜별 매출 확인 기능을 가진 소형 마트 프로그램입니다.

| 단계 | 파일 | 무엇을 바꿨나 |
|---|---|---|
| 1 | `01_0402_cart_dictionary.py` | 랜덤 장바구니를 만들고 품목별 개수를 셈. **리스트 대신 딕셔너리**를 쓴 이유를 주석으로 남김 |
| 2 | `02_menu_structure.py` | 가격·재고 딕셔너리 + 계산/재고/매출/종료 메뉴 뼈대 |
| 3 | `03_calc_stock_sales.py` | `계산()`, `재고관리()`, `매출관리()`를 함수로 구현 |
| 4 | `04_payment_confirm.py` | 결제 여부 확인 단계 추가 |
| 5 | `05_cancel_restore_stock.py` | 결제 취소 시 **재고 복구** 처리 |
| 6 | `06_flet_gui.py` | Flet GUI로 옮김 (콤보박스로 품목 선택) |
| 7 | `07_flet_cancel_cart.py` | GUI에서 구매 취소 기능 |
| 8 | `08_flet_quantity.py` | 수량 +/− 버튼 |
| - | `notebooks/` | 4/2 수업 문제 노트북, 4/15 클래스 버전 노트북 (재고·매출 CSV 저장) |

> 💡 **필기에서 정리한 판단 기준**
> 리스트는 키로 찾는 기능이 없어서 특정 값이 있는지 보려면 전체를 돌아야 한다.
> 딕셔너리는 `get()`으로 있는지 바로 확인할 수 있어서, 있으면 `+1`, 없으면 새로 추가하는 장바구니 카운트에 잘 맞는다.

## ✊ 가위바위보 (`rock_paper_scissors/`)

| 단계 | 파일 | 무엇을 바꿨나 |
|---|---|---|
| 1 | `01_console.py` | 콘솔 버전. 승패 판정표를 딕셔너리(`사전_가바보_심판`)로 만듦 |
| 2 | `02_flet_basic.py` | Flet 버튼으로 한 판 대결 |
| 3 | `03_flet_global_state.py` | 3판 선승제. `global` 변수로 점수를 관리하고 리셋 버튼 추가 |
| 4 | `04_flet_no_global_refactor.py` | 상태를 `main()` 안의 딕셔너리로 옮겨 **전역 변수를 줄임** |
| 5 | `05_flet_style.py` | 배경색, 결과 표시 등 화면 다듬기 |

배운 점: `on_click`과 `lambda`로 버튼에 값을 넘기는 방법, `page.update()`로 화면을 갱신하는 흐름, 그리고 전역 변수를 쓰다가 함수 안 상태로 옮기면서 생기는 차이를 익혔습니다.
