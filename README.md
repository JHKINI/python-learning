## 🔍 대표 실습

### 🎳 볼링 점수 계산기: 같은 문제를 8번 고쳐 쓴 기록
스트라이크·스페어 보너스처럼 **"나중에 나올 투구에 따라 점수가 정해지는 프레임"을 어떻게 관리할지**가 핵심이었습니다.
리스트 구조 설계 → 보너스 횟수 배열 → 함수 분리와 10프레임 예외 처리 → 다른 방식(프레임 인덱스 관리) 시도 → 점수 확정 여부를 따로 관리하는 최종본 → Flet GUI 순서로 발전했습니다.
➡️ [`02_projects/bowling`](02_projects/bowling)

### 🛒 마트 장바구니 · 재고 · 매출 관리
처음엔 리스트로 장바구니를 만들다가, **품목별 개수를 세려면 딕셔너리가 맞다**는 판단을 주석과 필기로 남겼습니다.
이후 메뉴 구조 → 결제 확인 → **결제 취소 시 재고 복구** → GUI → 수량 버튼 순으로 기능을 늘렸습니다.
➡️ [`02_projects/market`](02_projects/market)

### 📚 자료구조 직접 구현
같은 ADT를 **배열 버전과 연결 구조 버전**으로 각각 만들고, 그 자료구조로 응용 프로그램을 만들었습니다.
같은 미로를 스택(DFS), 큐(BFS), 우선순위 큐(출구까지 거리 기준)로 풀어 탐색 순서를 비교했습니다.
➡️ [`04_data_structures`](04_data_structures)

## ✍️ 이렇게 공부했습니다

- **구조부터 적고 코드로 옮기기**: 비밀번호 검증은 [의사코드 메모](03_oop/password/01_design_note.md)를 먼저 쓰고 구현했습니다. 미완성 설계 메모도 [`drafts/`](drafts)에 남겨 두었습니다.
- **콘솔 → 함수 분리 → 클래스 → GUI**: 볼링, 마트, 가위바위보, 계산기 모두 이 순서로 다시 만들었습니다.
- **함수 버전 → 클래스 버전**: 자료구조 첫 수업에서는 전역 변수와 함수로 만들고, 같은 기능을 클래스로 다시 작성했습니다. ([`class_0426_0430/`](04_data_structures/class_0426_0430))
- **직접 확인하기**: `queue.Queue`가 비었을 때 `get()`이 멈춘 것처럼 기다린다는 것을 실험 코드로 확인했습니다.
- **손으로 정리하기**: 수업마다 필기를 하고, 헷갈렸던 부분과 당시 고민("만들고 싶은 모습은 보이는데 무엇을 꺼내 써야 할지 모르겠다")도 함께 [정리](notes/python.md)했습니다.
