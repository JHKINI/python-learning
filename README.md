✊✌️✋ Flet 가위바위보 게임
파이썬의 UI 프레임워크인 Flet을 활용하여 만든 웹 기반 3판 선승제 가위바위보 게임입니다.

📝 프로젝트 소개
사용자와 컴퓨터가 가위바위보 대결을 펼치는 간단한 게임입니다. 누군가 먼저 3승을 달성하면 최종 승패가 결정되며, 게임 종료 후 리셋 버튼을 통해 다시 시작할 수 있습니다.

✨ 주요 기능
실시간 대결: 버튼을 클릭하면 컴퓨터가 무작위로 선택을 내리고 즉시 결과를 보여줍니다.

3판 선승제 로직: 먼저 3승을 달성하는 쪽이 최종 승리하며, 이후에는 버튼 입력이 차단됩니다.

게임 리셋: 승부가 난 후 '게임 리셋' 버튼이 나타나 점수를 초기화하고 다시 시작할 수 있습니다.

웹 기반 UI: 브라우저를 통해 실행되므로 별도의 창 관리 없이 깔끔하게 플레이 가능합니다.

🛠 사용 기술
Language: Python 3.x

Library: Flet (Flutter 기반 파이썬 UI 프레임워크)

Module: random (컴퓨터의 무작위 선택 구현)

🚀 실행 방법
1. 필수 라이브러리 설치
터미널(또는 CMD)에서 아래 명령어를 입력하여 Flet을 설치합니다.

Bash
pip install flet
2. 게임 실행
파이썬 파일을 실행합니다. (파일명이 main.py인 경우)

Bash
python main.py
실행 시 웹 브라우저가 자동으로 열리며 게임이 시작됩니다.

📂 코드 구조 설명
playerSelect(): 사용자의 입력을 받아 컴퓨터와 승패를 비교하고 점수를 계산합니다.

resetGame(): 점수와 화면 구성을 초기 상태로 되돌립니다.

main(): Flet 페이지의 레이아웃(제목, 버튼, 결과창 등)을 설정하고 화면에 배치합니다.

💡 학습 포인트 (초보자 메모)
전역 변수 활용: global 키워드를 사용하여 함수 밖의 변수를 수정하는 방법을 익혔습니다.

이벤트 처리: on_click과 lambda를 사용해 버튼 클릭 시 데이터를 전달하는 방식을 학습했습니다.

UI 업데이트: page.update()를 통해 상태 변화를 실시간으로 화면에 반영하는 구조를 이해했습니다.
