# 자료구조 실습 프로젝트

## 프로젝트 개요
배열, 연결리스트, 스택, 큐, 덱, 집합, 우선순위 큐와 미로 탐색(DFS/BFS/전략 탐색)을 Python으로 구현한 자료구조 실습 프로젝트입니다.

## 구성
1. 리스트 클래스(ListADT)
2. 라인 편집기(리스트 활용) 
3. 집합 클래스(SetADT)
4. 스택 클래스(StackADT)
5. 수식 계산기 (스택 활용)
6. 깊이우선 미로 탐색(DFS)
7. BFS 미로 탐색
8. 선형 덱 클래스
9. 큐 클래스 선형
10. 큐 클래스 원형
11. 너비우선 미로 탐색
12. 원형 덱 클래스
13. 선형 덱 클래스
14. 우선순위 큐 클래스
15. 전략적 미로 탐색

## 핵심 학습 내용
- 배열 기반 자료구조 구현
- 선형 구조와 원형 구조 비교
- 스택(LIFO)과 큐(FIFO)
- DFS와 BFS 탐색 원리
- 우선순위 큐를 이용한 전략 탐색

## 실행 환경
- Python 3.13.12
- Flet (일부 GUI 예제)

## 결론
자료구조의 기본 개념과 탐색 알고리즘을 직접 구현하며 동작 원리를 학습하였다.
