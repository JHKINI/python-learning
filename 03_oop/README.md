# 03. 클래스와 객체지향

> 2026년 4월 중순 · 수업 주제: 클래스 연습 (계산기, 전화번호부, 도서관리)

수업 필기에서 클래스를 **붕어빵 틀**에 비유해 정리했습니다.

> 클래스는 틀이고, 틀로 찍어낸 붕어빵이 객체다.
> 속성은 변수, 동작(메서드)은 함수다. 모든 객체가 같이 쓰는 값은 클래스에 두고, 객체마다 다른 값은 `self.`으로 넣는다.
> 상속을 하면 자식 클래스가 부모의 속성과 메서드를 그대로 쓸 수 있다. 다형성은 클래스가 달라도 같은 이름의 메서드로 다룰 수 있게 해주는 공통 인터페이스다.

(필기 전체: [`notes/python.md`](../notes/python.md#클래스와-객체))

| 1 | `01_class_basic.py` | 처음 만든 클래스. 덧셈 결과를 속성에 저장하고 확인하는 메서드 |
